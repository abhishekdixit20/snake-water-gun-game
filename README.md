# 🐍 Snake Water Gun Game

A simple Snake Water Gun game built using Python.

## 🎮 How to Play

The player chooses one of the following:

- 🐍 Snake
- 💧 Water
- 🔫 Gun

The computer randomly chooses one option, and the winner is decided based on the rules:

- Snake beats Water
- Water beats Gun
- Gun beats Snake

## 🛠️ Technologies Used

- Python
- Random Module

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python snake_water_gun.py
